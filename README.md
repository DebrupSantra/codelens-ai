# CodeLens AI

Frontend foundation for CodeLens AI, built with React and Vite.

## Getting started

```bash
npm install
npm run dev
```

## Available scripts

- `npm run dev` starts the Vite development server.
- `npm run build` creates a production build in `dist`.
- `npm run preview` serves the production build locally.

This repository currently contains frontend scaffolding only. Backend services and
AI functionality are intentionally out of scope.
